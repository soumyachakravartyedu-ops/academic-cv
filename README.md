# Dr. Soumyabrata Chakravarty — Academic Profile

A clean, responsive academic profile website for Dr. Soumyabrata Chakravarty, Mechanical Engineering researcher and Assistant Professor.

## Website

The site is a single static `index.html` designed to be:

- embedded in or linked from Google Sites
- hosted with GitHub Pages
- easy to maintain without a CMS
- responsive on desktop and mobile
- focused on research, publications, experience and academic identifiers

## Sections

- About
- Research Themes
- Academic & Research Experience
- Selected Publications
- Education
- Awards & Recognition
- VIDWAN / INFLIBNET
- ORCID
- Scopus
- Web of Science
- Google Scholar
- LinkedIn
- Contact

## Source

Profile content was structured from the academic CV maintained for Dr. Soumyabrata Chakravarty and the public academic-profile links supplied for the site.
